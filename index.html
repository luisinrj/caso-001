Configuração local

Conexão com OpenRouter

Cole sua chave do OpenRouter. Ela fica salva somente neste navegador. Cada aparelho ou navegador precisa configurar sua própria chave. Não coloque a chave no arquivo HTML nem no repositório público.

O modelo openrouter/free seleciona automaticamente um modelo gratuito disponível. Os modelos gratuitos têm limites de uso e podem variar.

IMPORTANTE: esta versão envia a chave diretamente do navegador para a API OpenRouter por HTTPS. A chave fica no armazenamento local do navegador, mas pode ser acessada por alguém com acesso ao aparelho e aos dados do navegador. Não coloque a chave no código HTML nem no repositório público. O jogo deve ser aberto por um endereço HTTPS (como GitHub Pages) para funcionar corretamente.
